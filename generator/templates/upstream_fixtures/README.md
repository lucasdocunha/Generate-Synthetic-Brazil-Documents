# XMLs de origem (fixtures upstream)

XMLs de NF-e, CT-e, MDF-e, NFS-e e CC-e herdados dos testes da lib BrazilFiscalReport
(ver `renderers/NOTICE.md`). Não são usados em tempo de geração: servem de **matéria-prima
para novos templates** do gerador (`generator/templates/<tipo>/v1/tpl_NNN/`), por exemplo
os modais do DACTE/DAMDFE e as variantes de DANFSe (intermediário, RTC, prod/hom).
